What I built this year

Take the Wheel

An AI browser agent. Personal project in JavaScript and Node.js.

  • A Chrome side panel and Node.js runner that let Claude drive a live browser tab, with streamed step events, resumable sessions and a stop control.
  • Safety limits live in code, not prompts: a fail-closed guard that checks every command before it runs, an isolated workspace, a token-authenticated local runner, budget and turn caps, and a submit lock that opens only when the user's task asks for it.
  • I found that the tool allowlist was never the real boundary: it let the agent reach the user's GitHub login and local files. The guard replaced it, with 67 test cases in CI across Node 20, 22 and 24.
  • I tested the agent like any system under test and caught it reporting 25 of 25 items done when 23 were verified. After I redesigned how it reads a page, it reached a verified 25 of 25.

ReqTrace

An AI pipeline for regulated engineering, built to be audited. Personal project in Python, on a fully synthetic device spec.

  • Reads a requirements specification and produces cited findings, a requirement-to-test trace matrix and a draft verification protocol. Every output is stamped for engineer review.
  • Rules that can be code are code. A guardrail drops any finding that cites a requirement that doesn't exist, and reused test steps are copied verbatim, never paraphrased.
  • A cheaper model earns a step only by passing the same eval gate. Three of four local-model routings failed it; the one that passed cut model cost 55%.

Market Terminal

A self-hosted market data pipeline and dashboard. Personal project in Python, SQLite and Flask.

  • Collects market data from about a dozen sources, stores every raw response, and renders dashboards, reports and an API from one immutable snapshot per run.
  • Built to be testable: any past run replays offline, and a missing input shows as “missing” with a reason instead of a placeholder number.
  • More than 400 offline tests. Any network call in a test is an error, and CI runs the whole suite a second time with the clock 400 days ahead.

AnyPS5

Open-source contribution to a PS5 compatibility layer, in C++, Python and CMake on macOS. Two pull requests, both merged by the maintainer.

  • A PS5 title failed on macOS hosts. I traced it to two missing libkernel imports that stopped it at load, then to a crash on its first C++ exception, when the unwinder hit a call that wasn't implemented.
  • I implemented kqueue/kevent and sceKernelGetModuleInfoFromAddr for macOS.
  • I added guest regression tests and macOS unwind fixtures, and ran the full 712-test suite before review.
